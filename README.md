# 商圈活动销售与客流归因

归因商圈节日活动客流与消费，支持商户对账、退款和可解释报表。

## 参与方与事实

主要参与方包括城市消费运营人员、商圈运营者、品牌与商户、活动承办方、统计审核人员。领域资料记录以下已经确认的事实：

- 中秋假期北京重点监测企业入账40.4亿元
- 70个重点商圈客流达2708.8万人次
- 潮流体验、灯光秀、夜跑、展销和非遗活动共同拉动消费

## 业务约束

- 客流采样去重
- 交易归因
- 退款冲正
- 样本审核
- 报表口径冻结
- 商户隔离

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/retail_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
